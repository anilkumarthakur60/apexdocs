AUDIT: responsive
######################################################################
SUMMARY: The Apex native UI is desktop-only in practice. There are 5 width breakpoints (1100 / 960 / 820 / 768 / 680) declared out of order, and nothing below 680px. The whole right pane is `display:none` from 1100px down with no drawer, tab, or fallback, so code samples, try-it-out, the response viewer, request history, and the schema-JSON block are unreachable on every tablet and phone. The mobile drawer's backdrop selector can never match (the element is a sibling of `#axui`, not a descendant), the drawer never closes on endpoint navigation, the toolbar's right cluster overflows off-screen under `html,body{overflow:hidden}` below ~400px, and `#apex-main{height:calc(100vh - Npx)}` permanently hides the last ~60-115px of every page on mobile Safari. Copy-permalink and all regex/constraint metadata are hover/title-only, so touch users cannot reach them. Nearly every interactive element is under 44x44px, including the 16x16 schema expand button that is the only way to open nested objects.
